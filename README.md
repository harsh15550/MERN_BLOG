# MERN Blog App

A full-stack **MERN (MongoDB, Express.js, React, Node.js)** blog application that allows users to register, log in, create blogs, view blogs by other users, and interact through features like category filtering and blog search.

🌐 **Live Demo**: [https://blogapplatest.netlify.app](https://blogapplatest.netlify.app)

---

## ✨ Features

- 📝 User Authentication (Register/Login)
- 🧑‍💻 Create, Edit, and Delete your own blogs
- 🔍 Search and filter blogs by category
- 🧾 Full blog details on a separate page
- 🧑 Profile page to view all blogs by a user
  
---

## 🛠️ Tech Stack

### Frontend
- React
- React Router DOM
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JSON Web Token (JWT) for authentication
